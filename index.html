Data Backup

Manual

Download a full snapshot of your live data (Customers, Projects, Leads, Marketing Opportunities, Bookings, Library, Time Sessions, Admins and Settings) as a JSON file, for safekeeping outside Firebase.

Restore from JSON

Restore records from a previously exported backup file. Each record in the file overwrites its matching record by ID — records not present in the file are left untouched, nothing is deleted. The Activity Log is never restored (it's append-only by design).

Migrate Bookings to Events

Bookings has been merged into Events — this copies every existing Booking record into Events (nothing is deleted from the original Bookings data). Safe to run more than once; already-migrated records are skipped.

Data Safety

Live

We take the security of your data seriously, and this area is under continuous review as the platform grows. Here's what's true today:

Dedicated project per clientYour data lives in its own Firebase project, not a shared multi-tenant database — it never sits alongside another customer's data.
Encrypted storage & transitHosted on Google Cloud infrastructure (Firestore), encrypted at rest and in transit by Google's own platform defaults.
Access controlEnforced by Firestore Security Rules — customers can only read or write their own records via their Portal login; admin actions are separately gated.
Tamper-evident audit trailEvery admin create, update, delete and promote action is logged in an append-only Activity Log that cannot be edited or deleted afterwards, even by an admin.
No exposed backend serverThe app talks directly to Firebase with no custom API server in between, which keeps the attack surface small.

What we don't claim: this platform has not yet been through an independent security audit, penetration test, or formal certification (e.g. SOC 2, ISO 27001). We'd rather be upfront about that than overstate it.
